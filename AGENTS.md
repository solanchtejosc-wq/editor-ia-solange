# Editor local de Solanch

Lee LEEME-PRIMERO.md. Usa los scripts Node existentes y FORMATO-DEL-PLAN.md para editar videos locales con FFmpeg. El asistente debe trabajar en esta carpeta; las grabaciones pertenecen al usuario.

Conserva el original. Prepara un plan JSON por proyecto, revisa con el usuario los cortes/textos y genera una muestra antes de la exportación completa. No inventes transcripciones. El detector de silencios solo propone pausas.

Skills disponibles: solanch-instalar, solanch-editar, solanch-exportar en .agents/skills (Codex) y .claude/skills (Claude Code). Si el menú no las detecta, lee su SKILL.md directamente. El kit no requiere modificar configuración global ni agregar servicios web.
