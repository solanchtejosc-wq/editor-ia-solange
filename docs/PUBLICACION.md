# Publicación de Solanch | Comunidad MINED/FWP
+
+- Landing: https://solanch-mined-fwp.netlify.app/
+- GitHub: https://github.com/solanchtejosc-wq/editor-ia-solange
+- Panel de Netlify: https://app.netlify.com/projects/solanch-mined-fwp
+- Registros: https://app.netlify.com/projects/solanch-mined-fwp/forms
+
+El proyecto está en el equipo gratuito de Solanch. El plan Free tiene límites de uso mensuales; se mantienen sus condiciones y no se añadieron servicios de pago.
+
+## Avance de las personas
+
+Las casillas Hecho guardan los pasos completados en el mismo navegador y dispositivo. El registro no sincroniza el avance ni crea una cuenta de usuario. La selección de Mac/Windows y Claude/Codex también se conserva en ese navegador.
+
+## Registro
+
+El formulario opcional solicita nombre, correo y consentimiento. Las respuestas se reciben en el panel privado de Netlify Forms, formulario `comunidad-solanch`. Se pueden revisar y exportar allí. La página explica el uso de los datos en `/privacidad/`. No se enviaron correos ni se configuraron campañas.
+
+## Actualización de la landing
+
+Los archivos están en `landing/dist/`. `netlify.toml` configura la carpeta base `landing` y publica `dist` sin compilación. Una vez conectado el repositorio, los cambios en la rama `main` despliegan la nueva versión.
+
+La dirección del repositorio se conserva para mantener los enlaces existentes. El nombre visible, los materiales y el PDF usan Solanch. El PDF con el nombre antiguo en su ruta se conserva como alias de compatibilidad y contiene la versión corregida.
