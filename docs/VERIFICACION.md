# Verificación de esta entrega

- JavaScript de landing y estudio: sintaxis revisada con Node.js.
- Enlaces y recursos locales: existen todos los destinos.
- Ruta: casilla persistente al recargar, ocho estaciones completas, aviso final y reinicio comprobados en Chrome.
- Estudio: muestra sintética de cuatro segundos; recorte de 0.5 a 3.5; título, marca y dos subtítulos; formato cuadrado; creación de archivo WebM de aproximadamente 0.2 MB comprobada. Vista previa de textos revisada.
- Subtítulos inválidos: se muestra el error y se desactiva la exportación. Cancelación: restaura la edición sin ofrecer un resultado cancelado.
- El archivo exportado no se reprodujo por separado: el control del navegador bloqueó la navegación directa a su dirección local de tipo blob. No se intentó eludir esa restricción.
- Vista de escritorio inspeccionada. Las reglas adaptativas están implementadas; la simulación de ancho móvil no se pudo confirmar con el control de viewport disponible.
- PDF: seis páginas renderizadas y revisadas; ocho casillas y tres campos interactivos verificados con sus apariencias.
- Comparación de archivos: ningún archivo de esta entrega coincide byte por byte con un archivo del editor anterior. La implementación del estudio y los textos se prepararon de nuevo. Esto no es una certificación jurídica.

El usuario debe comprobar imagen, sonido y aceptación del formato en su plataforma antes de compartir una exportación.
