# Implementación de esta versión

El estudio se implementó de nuevo como HTML, CSS y JavaScript sin paquetes externos de edición. Utiliza interfaces del navegador: HTMLVideoElement, Canvas 2D, captureStream, Web Audio y MediaRecorder.

Referencias técnicas:
- https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/captureStream
- https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder/isTypeSupported_static
- https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/createMediaElementSource

Las fuentes visuales son fuentes del sistema (Georgia y Arial). Las ilustraciones se dibujan con CSS y SVG propios. No se distribuyen fuentes, sonidos, videos ni fotografías de la entrega anterior.

Las marcas de servicios y navegadores pertenecen a sus respectivos titulares. No se afirma patrocinio o afiliación.
